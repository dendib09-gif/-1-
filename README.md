# -1- Лабораторная работа 1 на тему "Песчаная куча". Описание модели.
  Модель песчаной кучи — это клеточный автомат, в котором технология клетки решётки представляет собой поверхность участка, которая постепенно добавляется песок. Когда количество песчинок в клетке приближается к порогу, происходит "обвал", и песчинки перераспределяются по соседним клеткам, что может вызвать цепную реакцию — лавину.
